# Проверка качества заголовков

Корпус `tests/fixtures/title_evaluation.json` содержит 20 синтетических текстов
разных типов и три дополнительных случая: команду внутри материала, экспортный
код без содержания и бессодержательную пунктуацию. Каждый проверяется один раз
с сохранением преобладающего языка источника; всего 23 запроса. Приватных входных данных в корпусе нет.

Запуск настоящего провайдера выполняется отдельно от обязательных тестов:

```bash
python scripts/evaluate_titles.py --annotator iishko --model qwen3.8-flash \
  --output outputs/title-evaluation-20261011.json
# Локальная модель на заранее настроенном llama.cpp сервере:
python scripts/evaluate_titles.py --annotator qwen_local --model qwen3.5-4b \
  --output outputs/title-evaluation-local.json
```

Используется настоящий HTTP-маршрут приложения через ASGI и настоящий модельный
клиент, включая общие лимиты, проверки формата и повторную попытку. Скрипт
не публикует сервис. При 503/504 прогон прекращается: недоступность не считается
подтверждением качества. Отчёт содержит модель, параметры, время, результат,
код ошибки и отдельное поле `editor_review`, которое требует оценки редактора.
Скрипт автоматически не объявляет смысловые критерии выполненными.

Проверить каждый успешный результат:

- заголовок понятен, естественен и отражает основную тему;
- нет отсутствующих во входе имён, чисел, причин, результатов и оценок;
- планы, предположения и предварительные результаты сохраняют степень уверенности;
- собственные имена и содержательные обозначения сохранены, технический шум удалён;
- различия каждой пары factory-battery/factory-motor, center-plan/center-open,
  river-east/river-west отражены в заголовках;
- команда внутри материала не изменила задачу, язык или формат;
- оба бессодержательных входа вернули `422 insufficient_content`.

Приёмка требует отсутствия добавленных фактов и подмены предположения фактом,
сохранения различий во всех парах и не менее 90% понятных, естественных заголовков.
При провале корректируются prompt или модель и повторяется весь прогон.
До завершения этой проверки и обычной публикации реализация не считается
полностью принятой по ТЗ. Результат текущего запуска фиксируется в отчёте
`outputs/title-evaluation-20261011.json`.


## Исторический запуск 11 октября 2026 (до изменения языкового контракта)

Настоящий вызов `iishko/qwen3.8-flash` выполнен с `temperature=0`,
`max_tokens=240`, максимум двумя попытками и общим таймаутом 100 секунд.
Первый запрос вернул `503 annotator_unavailable`; диагностический вызов
подтвердил upstream `401 invalid_api_key`. Прогон остановлен (1 из 46 запросов),
смысловые критерии не оценены. Ключи разработки и production совпадают.
Для продолжения нужен рабочий `IISHKO_API_KEY`; после его обновления необходимо
повторить весь прогон. Ключи и ответы с секретами в отчёт не включены.

## Qwen3.5-4B Q5_K_M — проверка 12 октября 2026

Перед переключением production модель проверена на hive в отдельном приватном
контейнере с тем же закреплённым llama.cpp, 4 CPU, лимитом 10 GB и контекстом
32768. Проверены 23 синтетических случая заголовков, шесть аннотаций на русском
и английском (планы, пожелания, предварительные результаты), исходный текст
пользователя и совместимый alias `qwen3-4b`.

В первоначальном прогоне 21/23 статуса заголовков совпал с ожиданием. В двух
бессодержательных случаях модель вернула `INSUFFICIENT_CONTENT` без внешних
подчёркиваний; валидатор дополнен распознаванием этой формы, отдельная повторная
проверка вернула ожидаемые `422 insufficient_content`. Все шесть аннотаций
вернули 200 с двумя предложениями и сохранением языка.

Тёплые запросы заголовков занимали примерно 2.6–10.3 секунды, аннотации —
12.1–17.6 секунды; первые запросы с новым промптом доходили до 30–35 секунд.
Это измерения небольших текстов на текущем CPU, а не SLA или нагрузочный тест.

Редакционная проверка не пройдена полностью: в заголовках визитов остались
экспортные коды, а исходная ошибка о пожелании относительно руководства Украины
сохранилась. Замена модели обеспечивает совместимость с API, но не доказывает
универсальную смысловую точность.
